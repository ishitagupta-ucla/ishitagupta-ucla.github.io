Machine learning

RadioIQ: AI decision support for radiology

Problem
Radiology teams needed AI support for chest X-ray reads, and clinicians were hesitant to trust predictions they couldn't see the reasoning behind.
What I built
A pipeline over 300K+ DICOM chest X-rays (CLAHE, bone suppression) using RT-DETR, PSPNet and ResNet50 to detect and score 14 thoracic abnormalities. A Grad-CAM++ layer shows the region behind each prediction. Productionized with FastAPI and AWS S3 for hospital workflow integration.
94%accuracy across 14 abnormalities
>92% / >94%sensitivity / specificity
~$40Kper 3-year enterprise contract
  • Python
  • RT-DETR
  • PSPNet
  • ResNet50
  • Grad-CAM++
  • FastAPI
  • AWS S3
